Програма перевірки балів

Опис проєкту
Ця програма написана на C++. Вона потрібна для того, щоб порахувати загальну кількість балів за завдання та іспит і перевірити результат
студента.



Як працює програма:

Користувач вводить бали за завдання (assignment).

Потім вводить бали за іспит (exam).

Програма додає ці бали та записує результат у змінну total.

За допомогою if програма перевіряє умови й визначає статус.

У кінці програма виводить бали за завдання, бали за іспит, загальну суму та статус.



Умови програми

Якщо бали введені неправильно або перевищують максимальне значення, програма виводить помилку.

Якщо за завдання менше ніж 20 балів або за іспит менше ніж 30 балів, потрібно додатково опрацювати матеріал.

Якщо загальна сума становить 60 балів або більше і попередні умови не спрацювали, підсумкові умови вважаються виконаними.

Якщо загальна сума менша за 60 балів, кількості балів недостатньо.



Що використовувалося

C++ — мова програмування.

iostream — для введення та виведення інформації.

string — для зберігання тексту.

if — для перевірки умов.

cin і cout — для введення та виведення даних.



Як запустити програму

Відкрити проєкт у Visual Studio.

Запустити компіляцію програми.

Ввести бали за завдання та іспит.

Переглянути результат у консолі.
